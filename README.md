# rime-xhkk

基于 Rime（中州韵输入法引擎）的小鹤音形配置方案。在保留官方四码音形规则的基础上，补充了词库分层治理、四码顶屏、知音查形辅助、快捷键调频、标点直接上屏以及配套的桌面端加词工具。

---

## 主要特性与改动

### 1. 词库分层与现代化治理
- **剔除机械伪词**：清理了官方底册中残留的“太+形容词”、“看/想/要+动词”等 700+ 条机械分词碎片，减少重码干扰，恢复了“敌我矛盾”、“台湾”、“堪称”、“由此可见”等词汇的首选位置；
- **增补现代绝对空码词库（`flypy.modern`）**：筛选收录 950 条在现有词库中完全无重码的现代高频词（如“新质生产力”、“人脸识别”、“自动驾驶”、“共享单车”、“数字经济”等），零重码秒出；
- **行业与公文词库**：补充了 550+ 条 IT/软件工程术语库（`flypy.it`）与 200+ 条公文高频词库（`flypy.official`）；
- **地名校音与冲突控制（`flypy.places`）**：对 7,600+ 全国地名库进行了 570+ 处多音字校音（如六安、台州、丽水），且排序置于常用词之后，避免生僻地名抢占日常词首选；
- **私有词库隔离**：人名词库（`flypy.names`）、自用词库（`flypy.custom`）与置顶表（`flypy.user.top`）已被 `.gitignore` 忽略，避免同步到公开仓库时泄露个人隐私。

### 2. 四码顶字上屏（Dingshangping）
- **机制**：四码存在多个候选时，输入下一个词的第 1 个字母（第 5 击），当前首选词自动顶出上屏，新字母作为下一词首码继续输入；
- **开关**：默认开启；可通过快捷键 `F4` 或 `Ctrl + \`` 打开方案选项菜单随时切换【顶屏开 / 顶屏关】。

### 3. 知音查形辅助引擎（Chaxing）
知道读音但记不清首形或末形字根时，使用反引号 **`\``** 唤出辅助查询：
- **两码查首形（`双拼 + \``）**：输入 `gv\``，候选框列出该读音常用字并在右侧标注首形码（如 `1 规 f  2 归 l ...`），顺手按 `f` 收敛；
- **三码查末形（`双拼 + 首形 + \``）**：输入 `bof\``（读音 bo + 首形 f），候选框列出该字并标注末形码（如 `1 搏 c  2 拨 d ...`），顺手按 `c` 锁定上屏。

### 4. 标点优化与瞬发上屏
- **顿号（`\`）直接上屏**：修改标点映射为 `{ commit: 、 }`，在中文模式下按反斜杠键 `\` 顿号直接上屏，不再弹出标点选择菜单；
- **成对标点处理**：引号等成对符号保持合理闭合逻辑。

### 5. 快捷键调频（Super Sequence）
遇到重码词条需要临时调整顺序时，高亮选中该候选词直接使用快捷键：
- **`Ctrl + p`**：置顶该词
- **`Ctrl + j`**：向前移动一位
- **`Ctrl + k`**：向后移动一位
- **`Ctrl + l`**：重置为原始顺序
> 调频数据保存在本地独立 Rime `UserDb` 中，不修改底层词库文件。

### 6. 语句流手动造词
默认关闭自动造词，避免字库被意外输入的错别字污染：
- **4 码造词（`'` 引导）**：输入 `'vif'uie` 选“指示”上屏，系统按两字声韵提取公式保存，后续直接输入 `viui` 出词；
- **6 码造词（`~` 引导）**：输入 `~vif'uie` 选“指示”上屏，后续输入 `viuif` 或 `viuife` 精确出词；
- **生僻字补齐**：单字打不全 4 码时，第 4 码可用 `]` 补齐；
- **删词**：输入缩减码高亮候选词时按 `Ctrl + Delete`（Mac 上为 `Shift + Delete`）删除。

### 7. 配套加词工具（xhkk-builder）
基于 Go 开发的桌面端加词工具，源码位于 [tools/xhkk-builder](tools/xhkk-builder)，提供单文件可执行程序 [xhkk-builder.exe](tools/xhkk-builder/xhkk-builder.exe)：
- 输入汉字自动按小鹤公式生成 4 码，三字人名自动生成 3 码简码与 4 码全码；
- 内置多音字消歧与字频表，界面支持点击切换读音；
- 实时查重并显示词条状态（未收录 / 已存在 / 重码）；
- 回车写入对应词库并自动触发小狼毫静默重新部署。

### 8. 快捷工具
- **日期时间**（`o` 或 `/` 引导）：`orq` / `/rq`（日期）、`osj` / `/sj`（时间）、`odt`（完整日期时间）、`ott`（Unix 时间戳）、`oxq`（星期）、`onl`（农历）；
- **公历/农历反查**：`N20261125`；
- **金额大写**：`R1234.56` $\to$ 壹仟贰佰叁拾肆元伍角陆分；
- **简易计算器**：`V1+2*3` 实时得出结果。

## 常用按键与选词规则

| 操作 / 候选位置 | 推荐按键 | 传统按键 | 说明 |
| :--- | :--- | :--- | :--- |
| **首选 (第 1 候选)** | **`空格 (Space)`** | 数字 `1` | 四码重码时手动敲空格，或按下一词首字母自动顶屏 |
| **次选 (第 2 候选)** | **`分号 (;)`** | 数字 `2` | 右手基准位选词 |
| **3 选 (第 3 候选)** | **`句号 (.)`** | 数字 `3` | 右手无名指选词 |
| **顿号直接上屏** | **`\` (反斜杠)** | - | 直接上屏，无需多按空格 |
| **向下翻页** | **`等号 (=)`** | `Page Down` | 翻至下一页（每页 5 候选） |
| **向上翻页** | **`减号 (-)`** | `Page Up` | 翻回上一页 |

## 词库分层结构

词库位于 `flypy_dicts/` 目录下，在 [flypy.dict.yaml](flypy.dict.yaml) 中按优先级自上而下挂载：

```
flypy.dict.yaml (总索引)
 ├── flypy.user.top     (置顶层：专属置顶与全码防错，本地私有)
 ├── flypy.names        (人名层：人名词库，含 3 码简码，本地私有)
 ├── flypy.primary      (基础层：官方 6.7 万字词，经伪词清洗)
 ├── flypy.custom       (自用层：个人常用词组，本地私有)
 ├── flypy.official     (公文层：200+ 条公文政务高频四字套语)
 ├── flypy.it           (行业层：550+ 条 IT/软件工程/网安术语)
 ├── flypy.modern       (现代层：950 条现代生活与科技词，100% 绝对空码)
 ├── flypy.places       (地名层：7,600+ 条全国区县与乡镇地名)
 ├── flypy.secondary    (次选层：官方次选词库)
 └── flypy.user         (扩展层：官方 5,100 条三码填空词库)
```

> 私有词库（`flypy.user.top`、`flypy.names`、`flypy.custom`）已在 `.gitignore` 中配置，仓库提供了 `.example` 模板，按需复制去掉后缀即可使用。

## 安装与部署

### 1. Windows (小狼毫 Weasel)
1. 将本仓库文件复制到小狼毫用户配置目录（可在小狼毫右键菜单或注册表中查看，通常为 `%APPDATA%\Rime` 或自定义路径）；
2. 如需启用专属人名/私有词，复制对应 `.example` 文件并去掉后缀；
3. 右键任务栏小狼毫图标，点击 **“重新部署”**。

**桌面加词工具**：双击 [tools/xhkk-builder/xhkk-builder.exe](tools/xhkk-builder/xhkk-builder.exe) 即可运行。可复制到任意位置使用，工具会自动识别小狼毫配置目录。

### 2. macOS (鼠须管 Squirrel)
1. 将本仓库文件复制到 `~/Library/Rime/`；
2. 点击状态栏鼠须管图标，点击 **“重新部署”**。

### 3. Linux (Fcitx5-Rime / IBus-Rime)
1. 将文件复制到 `~/.local/share/fcitx5/rime/` 或 `~/.config/ibus/rime/`；
2. 执行 `rime_deployer` 或重启输入法。
