# rime-xhkk · 小鹤快码

基于 Rime（中州韵输入法引擎）定制的四码小鹤音形方案。方案严格遵循小鹤音形双拼双形编码规范，围绕**连续流盲打手感、现代词库治理、智能地名排位与原生桌面工具链**展开系统性工程优化，致力于为小鹤音形使用者提供轻快、纯净、开箱即用的现代化输入体验。

---

## 核心特性与特色

### 1. 配套原生桌面加词工具（xhkk-builder）

为了提供现代化、零门槛的词库扩充与维护体验，本项目自研了基于 Go 原生的轻量桌面端管理工具 **[xhkk-builder](tools/xhkk-builder)**（仓库随附免安装单文件 [xhkk-builder.exe](tools/xhkk-builder/xhkk-builder.exe)）：

- **即输即编**：输入汉字词汇，自动按小鹤标准音形算法计算四码，三字人名自动双写（4 码全码 + 3 码简码）；
- **四层多音字自动消歧**：结合字频与词级自然序底表自动推导最优读音；界面单字胶囊支持点击循环切换多音字，编码实时同步响应；
- **实时防重与冲突提示**：输入时实时扫描本地所有字典与内置词库，直观展示 `[未收录]`、`[已存在]` 或 `[重码]` 状态；
- **回车写入并后台静默部署**：回车秒级写入对应词库，并在后台异步触发小狼毫静默重新部署，全程无需手动干预；
- **原生极简与轻巧体积**：UI 遵循 Pitstop 现代原生设计准则，二进制经 UPX 压缩，免安装开箱即用。

> 源码与构建说明详见：[xhkk-builder 说明文档](tools/xhkk-builder/README.md)。

### 2. 词库系统性精馏与现代分层治理

遵循输入法词库的“减法哲学”与严谨的词长结构战略，对基础语料进行精细化治理与分层解耦：

- **基础语料精馏与成语权重优化**：
  在严格白名单机制保护下，系统性精简了无独立成词价值的高噪碎片短语（如“得买、谁家、想走”等），确保“敌我矛盾”（`dwmd`）、“台湾”（`tdwj`）、“堪称”（`kjig`）、“由此可见”（`yckj`）、“太原”（`tdyr`）等核心常用词与成语稳居首选位。
- **绝对空码现代科技与生活词库（`flypy.modern`）**：
  精选 950+ 条高频现代语料（二字词占 68%、四字词占 21%、三字词占 11%），且在其 4 码编码下**全库重码数为 0**。涵盖“新质生产力、人脸识别、自动驾驶、共享单车、数字经济、数字货币、表情包、扫码、刷脸、退货、包邮、打卡、内卷、躺平”等，100% 零重码秒出，完全不增加任何选词负担。
- **坚守 91.2% 自动上屏红线与冷码置换机制**：
  严格捍卫既有 31,657 个二字唯一码的自动上屏手感（全库保持 91.2% 超高自动上屏率），严禁盲目填塞次选破坏输入节奏；配套 `cold_swap.py` 工具链，结合权威语料词频与人工双向裁决，稳健置换极度生僻的陈旧码位。
- **无状态影子置顶架构（`flypy.user.top`）**：
  采用“实体归底册、控制归影子”的解耦设计，不修改基础词表，仅在置顶层精准配置关键现代核心词：
  - **`wx`**：首选出“微信”，次选保留“无线”，契合日常高频直觉；
  - **`uzhx`**（数字化）、**`bcyz`**（包邮）、**`yjsr`**（云计算）、**`duju`**（大数据）、**`yyvz`**（元宇宙）、**`dupb`**（短视频）、**`qklm`**（区块链）、**`ditj`**（低碳）等自然适配现代生活与工作语境。
- **行业与公文词库支撑**：
  补充 550+ 条 IT/软件工程原子术语（`flypy.it`）与 200+ 条公文政务高频四字套语（`flypy.official`）。
- **全国地名脱水精馏与自适应排位（`flypy.places`）**：
  将 4,800+ 条地名精馏为正规 2 字通名（如“诸城市”精馏为“诸城 `vuig`”，释放 `viui` 为“1 知识 2 只是”）；由独立 Lua 翻译器直接挂载并标注 `〔地名〕` 身份，配合自适应水位滤镜智能调度——无常用词时首选秒出，有常用词时自然顺延垫底或转入次页，永不挤占核心常用词的首选与分号位。
- **编码底表多音字严谨审计与名从主人正音**：
  对 7,468 个汉字的基础编码底表进行全量词级证据倒推审计，修正 45 个核心字的主流读音，杜绝派生工具误算错码；针对地名严格遵守“名从主人”原则，为中牟（mù）、涡阳（guō）、蚌埠（bèng）、乐清（yuè）等专名读音设立独立保护通道。
- **私有词库物理隔离**：
  人名词库（`flypy.names`）、自用词库（`flypy.custom`）与置顶表（`flypy.user.top`）默认被 `.gitignore` 保护，同步至公开仓库时完全杜绝隐私外泄。

### 3. 四码顶字上屏（连续流盲打免敲空格）

- **行云流水的连续输入**：四码唯一时自动上屏；四码遇重码时，无需刻意按空格确认，直接输入下一词的第 1 个字母（第 5 击），当前首选词立即自动顶出上屏，新字母作为下一词首码无缝延续，实现不敲空格的连续盲打。
- **轻量原生引擎**：基于原生轻量 Lua 处理器 `dingshangping.lua` 实现，无延迟、不产生额外性能负担。
- **随时可控**：默认开启；可随时按 `F4` 或 `Ctrl + \`` 打开方案菜单随时切换【顶屏开 / 顶屏关】。

---

### 4. 纳秒级极速响应与标点瞬发

- **消灭每键磁盘 I/O**：调频索引全量常驻内存，拔除每键触发磁盘数据库查询的开销，击键响应稳定平顺；
- **Lua 5.4 分代 GC 与局部化**：开启 Lua 原生分代垃圾回收（Generational GC），全链路核心过滤算法采用寄存器局部化缓存，彻底杜绝输入卡顿与内存抖动；
- **顿号与成对标点瞬发**：顿号（`\`）设置为 commit 瞬发上屏；括号、引号等成对符号自动补全闭合并将光标精准回退至中央。

---

### 5. 全链路知音查形辅助引擎（Chaxing）

自研 `chaxing.lua` 辅助引擎，解决输入时知道读音但一时拿不准字根的问题。使用反引号 **`\``** 即可唤出：

- **两码查首形（`双拼 + \``）**：输入 `gv\``，候选框列出该读音常用字并在右侧标注首形码（`1 规 f  2 归 l  3 轨 i ...`），顺手按 `f` 收敛锁定“规”；
- **三码查末形（`双拼 + 首形 + \``）**：输入 `bof\``（读音 bo + 首形 f），候选框列出该字并明确标注末形码（`1 搏 c  2 拨 d  3 播 t`），顺手按 `c` 锁定“搏”上屏；
- **三级字频赋权**：单字全量库（`flypydz`）注入《通用规范汉字表》三级权重，常用字稳居前列，生僻古字垫后，使查形结果精准聚焦于日常规范字。

---

### 6. 快捷键动态调频（基于 UserDb）

遇到重码词条需要临时微调顺序时，高亮选中该候选词直接使用快捷键：
- **`Ctrl + p`**：置顶该词
- **`Ctrl + j`**：向前移动一位
- **`Ctrl + k`**：向后移动一位
- **`Ctrl + l`**：重置为原始顺序
> 调频数据保存在本地独立的 Rime `UserDb` 数据库中，**不修改底层词库 YAML 文本**。

## 词库分层结构

词库位于 `flypy_dicts/` 目录下，在 [flypy.dict.yaml](flypy.dict.yaml) 中按优先级自上而下挂载：

```
flypy.dict.yaml (总索引)
 ├── flypy.user.top     (置顶层：专属置顶与全码防错，本地私有)
 ├── flypy.names        (人名层：人名词库，含 3 码简码，本地私有)
 ├── flypy.primary      (基础层：6.7 万精选字词)
 ├── flypy.custom       (自用层：个人常用词组，本地私有)
 ├── flypy.official     (公文层：200+ 条公文政务高频四字套语)
 ├── flypy.it           (行业层：550+ 条 IT/软件工程/网安术语)
 ├── flypy.modern       (现代层：950+ 条高频现代生活与科技词，100% 绝对空码)
 ├── flypy.secondary    (次选层：次选词库)
 └── flypy.user         (扩展层：5,100 条三码填空词库)

独立副翻译器：
 └── flypy.places       (地名层：4,800+ 条精馏通名地名，专属 Lua 翻译器 + 自适应水位滤镜)
```

## 常用按键速查

| 操作 / 候选位置 | 推荐按键 | 传统按键 | 说明 |
| :--- | :--- | :--- | :--- |
| **首选 (第 1 候选)** | **`空格 (Space)`** | 数字 `1` | 四码重码时手动敲空格，或直接敲下一词首字母自动顶屏 |
| **次选 (第 2 候选)** | **`分号 (;)`** | 数字 `2` | 右手基准位盲打次选 |
| **3 选 (第 3 候选)** | **`句号 (.)`** | 数字 `3` | 右手无名指选词 |
| **向下翻页** | **`等号 (=)`** | `Page Down` | 翻至下一页（每页 5 候选） |
| **向上翻页** | **`减号 (-)`** | `Page Up` | 翻回上一页 |

## 其它内置功能（简要）

- **语句流手动造词**：输入 `'` 引导四码造词（如 `'vif'uie` $\to$ `viui`）；高亮候选时按 `Ctrl + Delete` 删词；
- **辅助输入**：`orq` 输入日期，`osj` 输入时间，`N20261125` 反查农历，`R` 引导大写数字，`V` 引导简易计算器。

## 安装与部署

### 1. Windows (小狼毫 Weasel)
1. 将本仓库文件复制到小狼毫用户配置目录（通常为 `%APPDATA%\Rime` 或用户自定义路径）；
2. 如需启用专属人名/私有词，复制对应 `.example` 模板并去掉后缀；
3. 右键任务栏小狼毫图标，点击 **“重新部署”**。

**使用加词工具**：双击 [tools/xhkk-builder/xhkk-builder.exe](tools/xhkk-builder/xhkk-builder.exe) 即可运行。可复制到桌面使用，工具会自动识别小狼毫配置目录。

### 2. macOS (鼠须管 Squirrel)
1. 将本仓库文件复制到 `~/Library/Rime/`；
2. 点击状态栏鼠须管图标，点击 **“重新部署”**。

### 3. Linux (Fcitx5-Rime / IBus-Rime)
1. 将文件复制到 `~/.local/share/fcitx5/rime/` 或 `~/.config/ibus/rime/`；
2. 执行 `rime_deployer` 或重启输入法。
