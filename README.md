# rime-xhkk · 小鹤快码

基于 Rime（中州韵输入法引擎）定制的四码小鹤音形方案。在继承小鹤四码音形规则的基础上，重点针对原版方案在**词库质量、加词体验与连续盲打手感**上的长期痛点进行了深度重构与工具链补全。

---

## 核心特性与特色改动

### 1. 配套原生桌面加词工具（xhkk-builder）

针对小鹤音形日常扩词需要“心算四码、查多音字、手动改 YAML、手动点部署”的繁琐流程，本项目开发了纯 Go 原生桌面端工具 **[xhkk-builder](tools/xhkk-builder)**（仓库直接提供免安装单文件 [xhkk-builder.exe](tools/xhkk-builder/xhkk-builder.exe)）：

- **即输即编**：输入汉字词汇，自动按小鹤标准公式计算四码，三字人名自动双写（4 码全码 + 3 码简码）；
- **四层多音字自动消歧**：结合官方字频表、6.8 万词自然序底表与常用名库自动推导最优读音；界面单字胶囊支持点击循环切换多音字，编码实时同步响应；
- **实时防重与冲突提示**：输入时实时扫描本地所有字典与内置官方库，展示 `[未收录]`、`[已存在]` 或 `[重码]` 状态；
- **回车写入并后台静默部署**：回车秒级写入对应词库，并在后台异步触发小狼毫静默重新部署，全程无需手动干预。

> 源码与构建说明详见：[xhkk-builder 说明文档](tools/xhkk-builder/README.md)。

### 2. 词库深度现代化与词组改造

针对小鹤音形官方词库“年代久远、现代词缺失、机械切词碎片霸凌成语”的经典问题，实施了系统性的词库分层治理：

- **两阶段伪词脱水清洗**：
  官方 6.8 万基础库中残留了大量早期机器分词切出的“动词+虚词”、“虚词+动词”等机械搭配碎片。本项目在严格白名单保护下，系统性清除了 700+ 条无独立成词价值的伪词碎片（如“得买、谁家、太矮、想走、要比”等），直接解救并恢复了“敌我矛盾”（`dwmd`）、“台湾”（`tdwj`）、“堪称”（`kjig`）、“由此可见”（`yckj`）、“太原”（`tdyr`）等一批正规词汇的首选地位。
- **开垦 950 条“绝对空码”现代科技与生活词库（`flypy.modern`）**：
  对标现代汉语权威语料，严格筛选出在其 4 码编码下**全库重码数为 0** 的高频现代词（二字词占 68%、四字词占 21%、原子三字词占 11%）。涵盖“新质生产力、人脸识别、自动驾驶、共享单车、数字经济、数字货币、表情包、扫码、刷脸、退货、包邮、打卡、内卷、躺平”等，100% 零重码秒出，不增加任何重码负担。
- **无状态影子置顶解决核心词频度倒挂（`flypy.user.top`）**：
  在最顶层的无状态影子置顶表中，精准配置了 9 大现代超级核心词：
  - **`wx`**：首选直接出“微信”（次选为“无线”），契合日常输入直觉；
  - **`uzhx`**：首选出“数字化”（原首选为“手滑”）；
  - **`bcyz`**：首选出“包邮”（原首选为“保佑”）；
  - **`yjsr`**（云计算）、**`duju`**（大数据）、**`yyvz`**（元宇宙）、**`dupb`**（短视频）、**`qklm`**（区块链）、**`ditj`**（低碳）等全部扶正为首选。
- **行业与公文词库补充**：
  补充了 550+ 条 IT/软件工程原子术语库（`flypy.it`）与 200+ 条公文政务高频四字词库（`flypy.official`）。
- **全国地名校音与冲突控制（`flypy.places`）**：
  收录 7,600+ 全国区县与乡镇地名，经过 570+ 处多音字人工校核（六安、台州、丽水等），且挂载排序置于常规常用词之后，避免生僻地名抢占日常词首选（如平果不抢苹果、开原不抢开源）。
- **私有词库物理隔离**：
  用户人名词库（`flypy.names`）、自用词库（`flypy.custom`）与置顶表（`flypy.user.top`）已被 `.gitignore` 忽略，同步配置到公开仓库时绝不泄露个人隐私。

### 3. 四码顶字上屏（连续流盲打免敲空格）

- **痛点**：小鹤音形在 Rime 下四码无重码时能自动上屏，但一旦有重码（多个候选），必须手动敲空格才能上屏，频繁打断盲打节奏。
- **机制**：接入原生的轻量 Lua 处理器 `dingshangping.lua`。当四码存在多个候选时，直接输入下一个词的第 1 个字母（第 5 击），当前首选词自动顶出上屏，新字母作为下一词首码继续输入，实现不敲空格的连续盲打。
- **开关**：默认开启；可随时按 `F4` 或 `Ctrl + \`` 打开方案菜单切换【顶屏开 / 顶屏关】。

---

### 4. 全链路知音查形辅助引擎（Chaxing）

自研 `chaxing.lua` 辅助引擎，解决输入时知道读音但记不清字根的问题。使用反引号 **`\``** 即可唤出：

- **两码查首形（`双拼 + \``）**：输入 `gv\``，候选框列出该读音常用字并在右侧标注首形码（`1 规 f  2 归 l  3 轨 i ...`），顺手按 `f` 收敛锁定“规”；
- **三码查末形（`双拼 + 首形 + \``）**：输入 `bof\``（读音 bo + 首形 f），候选框列出该字并明确标注末形码（`1 搏 c  2 拨 d  3 播 t`），顺手按 `c` 锁定“搏”上屏；
- 单字全量库（`flypydz`）注入了《通用规范汉字表》三级权重，常用字稳居前列，生僻古字垫后，彻底解决查形被生僻古字霸屏的问题。

---

### 5. 快捷键动态调频（基于 UserDb）

遇到重码词条需要临时微调顺序时，高亮选中该候选词直接使用快捷键：
- **`Ctrl + p`**：置顶该词
- **`Ctrl + j`**：向前移动一位
- **`Ctrl + k`**：向后移动一位
- **`Ctrl + l`**：重置为原始顺序
> 调频数据保存在本地独立的 Rime `UserDb` 数据库中，**不修改底层词库 YAML 文本**。

## 词库分层结构

词库位于 `flypy_dicts/` 目录下，在 [flypy.dict.yaml](flypy.dict.yaml) 中按优先级自上而下挂载：

```
flypy.dict.yaml (总索引)
 ├── flypy.user.top     (置顶层：专属置顶与全码防错，本地私有)
 ├── flypy.names        (人名层：人名词库，含 3 码简码，本地私有)
 ├── flypy.primary      (基础层：官方 6.7 万字词，经两阶段伪词脱水)
 ├── flypy.custom       (自用层：个人常用词组，本地私有)
 ├── flypy.official     (公文层：200+ 条公文政务高频四字套语)
 ├── flypy.it           (行业层：550+ 条 IT/软件工程/网安术语)
 ├── flypy.modern       (现代层：950 条现代生活与科技词，100% 绝对空码)
 ├── flypy.places       (地名层：7,600+ 条全国区县与乡镇地名)
 ├── flypy.secondary    (次选层：官方次选词库)
 └── flypy.user         (扩展层：官方 5,100 条三码填空词库)
```

## 常用按键速查

| 操作 / 候选位置 | 推荐按键 | 传统按键 | 说明 |
| :--- | :--- | :--- | :--- |
| **首选 (第 1 候选)** | **`空格 (Space)`** | 数字 `1` | 四码重码时手动敲空格，或直接敲下一词首字母自动顶屏 |
| **次选 (第 2 候选)** | **`分号 (;)`** | 数字 `2` | 右手基准位盲打次选 |
| **3 选 (第 3 候选)** | **`句号 (.)`** | 数字 `3` | 右手无名指选词 |
| **向下翻页** | **`等号 (=)`** | `Page Down` | 翻至下一页（每页 5 候选） |
| **向上翻页** | **`减号 (-)`** | `Page Up` | 翻回上一页 |

## 其它内置功能（简要）

- **语句流手动造词**：输入 `'` 引导四码造词（如 `'vif'uie` $\to$ `viui`），输入 `~` 引导六码造词；高亮候选时按 `Ctrl + Delete` 删词；
- **辅助输入**：`orq` 输入日期，`osj` 输入时间，`N20261125` 反查农历，`R` 引导大写数字，`V` 引导简易计算器。

## 安装与部署

### 1. Windows (小狼毫 Weasel)
1. 将本仓库文件复制到小狼毫用户配置目录（通常为 `%APPDATA%\Rime` 或用户自定义路径）；
2. 如需启用专属人名/私有词，复制对应 `.example` 模板并去掉后缀；
3. 右键任务栏小狼毫图标，点击 **“重新部署”**。

**使用加词工具**：双击 [tools/xhkk-builder/xhkk-builder.exe](tools/xhkk-builder/xhkk-builder.exe) 即可运行。可复制到桌面使用，工具会自动识别小狼毫配置目录。

### 2. macOS (鼠须管 Squirrel)
1. 将本仓库文件复制到 `~/Library/Rime/`；
2. 点击状态栏鼠须管图标，点击 **“重新部署”**。

### 3. Linux (Fcitx5-Rime / IBus-Rime)
1. 将文件复制到 `~/.local/share/fcitx5/rime/` 或 `~/.config/ibus/rime/`；
2. 执行 `rime_deployer` 或重启输入法。
