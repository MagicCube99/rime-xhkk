# rime-xhkk · 小鹤音形快捷调频与极速造词方案

基于 Rime（中州韵输入法引擎）定制的四码小鹤音形高效输入方案。

> **专为音形盲打与知识工作者打造**：四码极速盲打 · 四码顶字上屏 · 快捷键自由调频 · 内置原生速加词小工具 · 模块化行业词库 · 知音查形辅助 · 零隐私泄漏

`rime-xhkk` 致力于为四码音形盲打与知识工作者提供极致、现代、纯净的输入体验。方案构建了严谨解耦的模块化词库分层体系，扩充了 IT、公文与地名标准库，内置开箱即用的轻量级原生桌面速加词工具，并深度融合了全链路知音查形与四码顶字上屏等核心体验。

## 一、 核心特性

### 1. 内置 xhkk-builder 原生桌面速加词小工具（推荐）

为了彻底终结小鹤音形用户“改 YAML 怕格式缩进错位、加新词需心算四码、遇多音字需翻字表、加完词还得手动右键重新部署”的繁琐流程，本项目量身开发了配套的纯 Go 原生桌面端工具 **[xhkk-builder](tools/xhkk-builder)**（直接内置于 `tools/xhkk-builder/xhkk-builder.exe`，免安装绿色单文件，毫秒级冷启动，零外部环境依赖）：

- **即输即编**：输入汉字词汇，自动按小鹤标准公式生成 4 码，三字人名自动双写（4码全码 + 3码简码）；
- **四层多音字消歧体系**：基于官方字频、6.8 万基础词库及常用名库自动选择最优读音，界面单字读音胶囊支持鼠标点击一键循环切换；
- **实时查重与冲突提示**：实时扫描本地字典与内置官方基础词库，展示 `[未收录]`、`[已存在]` 或 `[重码]` 状态徽标，杜绝重复录入；
- **回车一键写入并后台静默热部署**：按回车键秒级写入对应词库，并在后台异步触发小狼毫静默重新部署，全程无感、心流不中断。

> 源码与进阶指引详见：[xhkk-builder 说明文档](tools/xhkk-builder/README.md)。

---

### 2. 快捷键自由调频（来自万象拼音 Lua 引擎）

遇到重码词条需要调整前后顺序或置顶时，高亮选中该候选词，直接使用快捷键：

| 快捷键 | 功能说明 | 适用场景 |
| :--- | :--- | :--- |
| **`Ctrl + p`** | **一键置顶** | 将高频使用的重码词固定到第 1 候选 |
| **`Ctrl + j`** | **向前（左）移动一位** | 精细微调候选顺序 |
| **`Ctrl + k`** | **向后（右）移动一位** | 降低低频词优先级 |
| **`Ctrl + l`** | **重置自定义位置** | 恢复词库原生物理顺序 |

> **特性**：调频数据保存在本地独立的 Rime `UserDb` 数据库中，**完全不修改、不污染底层词库 YAML 文本**，支持跨设备同步。

### 3. 语句流手动造词（4 码 + 6 码双模引擎）

默认关闭自动造词（`encode_commit_history: false`），杜绝字库污染。需要造词时采用单引号分词语句流：

#### ① 4 码造词（`'` 单引号引导）
- **操作方式**：输入 `'` 引导，每个单字输入全码并用 `'` 隔开，选词上屏。
- **示例**：输入 `'vif'uie`，候选框出现“指示”，按空格或数字上屏。
- **底层动作**：系统自动按小鹤官方 4 码公式压缩提取（2字取声韵+声韵 `AaAbBaBb` -> `viui`），存入用户词库。
- **后续使用**：以后直接敲 **`viui`**，“指示”立即排在首选（四码唯一直接自动上屏）。

#### ② 6 码造词（`~` 波浪号引导）
- **操作方式**：输入 `~` 引导，单字之间用 `'` 隔开，选词上屏。
- **示例**：输入 `~vif'uie`，选“指示”上屏。
- **底层动作**：提取声韵及首末字第一形码（`AaAbBaBbAcBc` -> `viuife`）。
- **后续使用**：输入 **`viuif`**（5码）或 **`viuife`**（6码）精准出词，极其适合容易重码的 2 字词。

#### ③ 辅助技巧
- **生僻字补齐**：单字若打不全 4 码，第 4 码用 **`]`** 补齐（例如 `'vif]'uie`）；
- **一键删词**：输入缩减码高亮该候选词时，按 **`Ctrl + Delete`**（Mac 上为 `Shift + Delete`）即可从本地用户库中彻底抹除该词条。

### 4. 对齐官方的“知音查形辅助引擎”（全链路查形）

打字时知道读音但记不清字根时，使用反引号 **`\``**（位于 Tab 键上方、数字 1 左侧）即刻唤出辅助查询，覆盖首形与末形全场景：

#### ① 两码查首形（`双拼两码 + \``）
- **适用场景**：知道读音，但不确定首形。
- **即刻呈现常用字序列**：输入 `gv\``，候选框立即输出官方自然字频序列，字右侧清晰展示首形码：
  - **第 1 页**：`1 规 f  2 归 l  3 轨 i  4 桂 m  5 圭 t`
  - **第 2 页**：`1 鬼 p  2 硅 u  3 瑰 w  4 跪 z  5 龟 d`
- **首形动态收敛**：看到提示后顺手敲击对应首形码（如按 `p` 变为 `gv\`p`），候选自动收敛锁定“鬼”，空格直接上屏；

#### ② 三码查末形（`双拼两码 + 首形 + \``）
- **适用场景**：知道读音与首形，但卡在最后一位末形码。
- **末形提示序列**：输入 `bof\``（读音 `bo` + 首形 `f` + 反引号），候选即刻列出该首形字并清晰标注末形码：
  - `1 搏 c  2 拨 d  3 播 t  4 播`
- **末形动态收敛**：顺手敲击末形码（如按 `c` 变为 `bof\`c`），秒级锁定“搏”空格上屏，无需反复翻字表；

#### ③ 全量单字规范分级赋权
- 单字全量库（`flypydz`）注入了国家《通用规范汉字表》三级权威权重，常用字稳居前列，生僻古字垫后，彻底告别生僻字霸屏。

---

### 5. 基础按键与选词规则

- **自动上屏与四码顶字上屏**：
  - **无重码自动上屏**：四码唯一时自动秒上屏；分号 `;` 引导单字符快符自动上屏；
  - **有重码顶字上屏（连续流盲打）**：当四码存在多个候选时，直接输入下一个词的第 1 个字母（第 5 击），当前首选词自动顶出上屏，手指无需停顿按空格，输入心流不中断（*默认开启；支持按 `F4` 或 `Ctrl + \`` 打开方案选项菜单随时切换【顶屏开 / 顶屏关】*）；
- **首选与次选**：`空格` 手动上屏首选，`分号 ;` 次选，`句号 .` 三选；
- **翻页**：`减号 -` 上翻页，`等号 =` 下翻页；
- **部件组字**：`ok` 引导双拼拆字（如 `oknqnqnq` -> 犇）。

---

### 6. 实用内置工具箱

- **日期与时间快捷输入**（支持 `o` 或 `/` 引导，拼音首字母缩写即出）：
  - **`orq`** 或 **`/rq`**（日期 riqi）：当前日期（首选 `2026-11-21`，候选包含年月日及完整时间）
  - **`osj`** 或 **`/sj`**（时间 shijian）：当前纯时间（`19:50`、`19:50:02`、`下午07:50`、`19点50分02秒`）
  - **`odt`** 或 **`/dt`**（Date+Time）：完整日期时间（`2026-11-21 19:50:02`）
  - **`ott`** 或 **`/tt`**（TimeStamp）：Unix 时间戳（秒级、毫秒级与 RFC3339 格式）
  - **`oxq`** 或 **`/xq`**（星期 xingqi）：当前星期（`星期六`、`周六`）
  - **`onl`** 或 **`/nl`**（农历 nongli）：农历年月日与干支
  - **`ojq`** 或 **`/jq`**（节气 jieqi）：节气信息；**`ojr`** 或 **`/jr`**（节日 jieri）：节日倒计时
  - **`N20261121`**：输入 N + 日期快速反查公历、农历与相对天数
- **大写数字与金额**：输入 `R1234.56` 输出大写金额“壹仟贰佰叁拾肆元伍角陆分”；
- **超级计算器**：输入 `V1+2*3` 实时得出计算结果。

## 二、 科学解耦的模块化词库体系

词库统一位于 `flypy_dicts/` 目录下，在 [flypy.dict.yaml](flypy.dict.yaml) 的 `import_tables` 中挂载，权责清晰：

```
flypy.dict.yaml (词库总索引)
 ├── flypy.user.top     (置顶层：[可选] 专属置顶与全码防错词库，本地私有)
 ├── flypy.names        (人名层：[可选] 用户专属人名词库，含 3 码简码，本地私有)
 ├── flypy.primary      (基础层：[官方] 官方 6.8 万首选自然序码表)
 ├── flypy.custom       (自用层：[可选] 用户自用专属词汇与短语，本地私有)
 ├── flypy.official     (公文层：[扩展] 200+ 条公文政务高频四字套语，4 码秒出)
 ├── flypy.it           (行业层：[标准] 550+ 条 IT/软件工程/网安大厂标准词)
 ├── flypy.places       (地名层：[标准] 7,600+ 条全国省市县区 + 浙江乡镇街道)
 ├── flypy.secondary    (次选层：[官方] 官方次选词库)
 └── flypy.user         (扩展层：[官方] 官方 5,100 条三码填空词库)
```

### 1. 专业与扩展词库亮点
- **IT / 软件工程 / 网安标准词库（`flypy.it`）**：550+ 条精选术语，实现“大复合词（关系型数据库、分布式系统、微服务架构）与原子拆分词（数据库、分布式、微服务、读写、分库、分表、线程、协程、心跳）”双向覆盖；
- **全国地名库（`flypy.places`）**：7,600+ 条全国区县 + 浙江乡镇街道，经过 570+ 处多音地名严密校音（石狮市、六安、台州、丽水...），并执行了全库零冲突过滤，杜绝偏远地名截断劫持日常词（苹果不被平果抢、评估不被平谷抢、开源不被开原抢、但是不被石室抢）；
- **公文政务高频套语库（`flypy.official`）**：200+ 条高频四字词（顶层设计、深入贯彻、全面推进、稳中求进、守正创新、多措并举、立足实际、压实责任），4 码秒出；
- **IT 英文专有名词自动规范（`en_custom`）**：内置 150+ 条技术名词大小写自动映射（`JSON`、`API`、`GitHub`、`Docker`、`ChatGPT`、`DeepSeek`...），全小写盲打直接出规范大小写。

### 2. 个人自定义词库扩展指引（本地好用 · 云端绝密）
方案预留了三个私有词库扩展接口，已被 `.gitignore` 物理隔离，**彻底解决程序员将个人配置同步到 GitHub 时泄露同事人名、内部行话与私密短语的顾虑**：
- **`flypy.user.top.dict.yaml`**：专属全码防错与核心词置顶库（最高优先级）；
- **`flypy.names.dict.yaml`**：专属人名词库（支持 3 码简码与 4 码全码）；
- **`flypy.custom.dict.yaml`**：专属自用词库（支持个人自定词组、缩写与短语）。

> 仓库提供了对应的 `.example` 示例模板，按需复制并重命名去掉 `.example` 即可直接使用；更推荐直接使用内置的 [xhkk-builder](tools/xhkk-builder) 桌面端自动添加！

## 三、 安装与部署说明

### 1. Windows (小狼毫 Weasel)
1. 将本仓库所有文件复制到小狼毫的用户配置目录（通常位于 `%APPDATA%\Rime`）；
2. 如需启用专属人名/私有词，复制对应 `.example` 文件并重命名去掉后缀（或直接运行 `tools/xhkk-builder/xhkk-builder.exe` 录入）；
3. 右键任务栏小狼毫图标，点击 **“重新部署”**。

**打开加词工具（Windows）**：双击 [xhkk-builder.exe](tools/xhkk-builder/xhkk-builder.exe) 即可加词。也可以把 EXE 复制到桌面或其他方便的位置，再双击打开；它会自动查找小狼毫用户配置目录，不必放在该目录内。

### 2. macOS (鼠须管 Squirrel)
1. 将本仓库文件复制到 `~/Library/Rime/`；
2. 点击状态栏鼠须管图标，点击 **“重新部署”**。

### 3. Linux (Fcitx5-Rime / IBus-Rime)
1. 复制到 `~/.local/share/fcitx5/rime/` 或 `~/.config/ibus/rime/`；
2. 执行 `rime_deployer` 或重启输入法完成构建。
