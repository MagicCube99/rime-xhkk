# rime-xhkk 词条速加工具 (xhkk-builder)

为小鹤音形 Rime 方案量身打造的极简、轻量、高精度词条快速添加与自动化部署工具。

---

## 一、 工具定位与初衷

在小鹤音形输入法日常使用中，扩充个人词库往往是一件繁琐且容易出错的事：
1. **手动编辑 YAML 易错**：需要手动查找并打开 `flypy.custom.dict.yaml` 或 `flypy.names.dict.yaml`，若缩进格式或制表符错误，会导致整个词库加载失败；
2. **双拼与四码公式换算繁琐**：录入新词时，需要心算单字声韵、对应双拼键位，并按小鹤 2/3/4/多字词规则拼装 4 码（或人名 3 码简码）；
3. **多音字易混淆**：遇上“行”、“长”、“重”等多音字时，手动查字表确认声韵费时费力；
4. **重码与重复未预知**：无法直观得知该词是否已被词库收录、编码是否与既有高频词重码；
5. **部署繁琐中断心流**：保存文件后，还需手动在任务栏右键小狼毫并点击“重新部署”，等待数秒。

**xhkk-builder** 彻底解决了上述痛点——启动仅需毫秒级、界面小巧精悍（400x360）、无任何外部环境依赖，提供 **“输入汉字 -> 自动编码 -> 实时查重 -> 回车写入并静默部署”** 的一体化流畅体验。

---

## 二、 核心特性

- **极简原生 GUI**：基于 `egoist/mygo` 声明式原生 UI 构建，单可执行文件，无 Electron 笨重运行时，内存占用仅约 15MB；
- **四层多音字自动消歧体系**：
  - **Layer 1**：基于 `primary_chars.tsv` 提取小鹤音形官方最高频单字基准读音；
  - **Layer 2**：内置官方 6.8 万词自然序码表（`flypy.primary`）与三码填空表（`flypy.user`），提取字频与上下文词组读音；
  - **Layer 3**：集成精校高频地名/人名/多音词常用读音表；
  - **Layer 4**：兜底通用拼音字音库。
  - **交互式读音切换**：界面单字胶囊实时显示提取读音，多音字一键点击循环切换，编码与查重状态实时同步响应。
- **严格遵循小鹤音形编码公式**：
  - **二字词**：首字声韵 + 末字声韵（$AaAbBaBb$）；
  - **三字词**：前两字声母 + 末字声韵（$AaBaCaCb$）；
  - **四字及以上词**：前三字声母 + 末字声母（$AaBaCaDa$）；
  - **人名词库增强**：三字人名自动生成四码全码与前三声母三码简码（如“何海峰” -> `hhfu` 与 `hhf`）。
- **实时防重与冲突提示**：
  - 输入时实时扫描用户目录所有字典与内置官方基础词库；
  - `[未收录]`（绿色）：无冲突新词，可放心添加；
  - `[已存在: xx]`（红色）：该词在当前字典已收录，自动禁用提交防重；
  - `[重码: 当前首选为'xxx']`（黄色）：该编码已被其他词占用，允许提交作为次选出词。
- **原子化追加与静默后台部署**：
  - 自动备份与安全原子追加到 `flypy.custom.dict.yaml` 或 `flypy.names.dict.yaml`，严格遵守标准 Tab 分隔符与 YAML 词库规范；
  - 自动探测 Windows 注册表（HKCU / HKLM）及默认安装路径中的 `WeaselDeployer.exe`；
  - 提交后后台异步静默触发 `/deploy`，无需手动干预，数秒内小狼毫即可完成加载。

## 三、 构建与打包

### 前置环境
- Go 1.22 或更高版本（纯 Go 实现，`CGO_ENABLED=0`，无 C 编译器依赖）。

### 1. 编译指令

进入工具目录：
```bash
cd tools/xhkk-builder
```

#### 本地调试构建（带控制台输出）
```bash
go build -o xhkk-builder.exe ./cmd/builder
```

#### 生产发布推荐构建（去除符号表、隐藏控制台黑框）
```bash
go build -ldflags="-s -w -H=windowsgui" -o xhkk-builder.exe ./cmd/builder
```

### 2. 运行自动化测试
```bash
go test ./... -v
```

## 四、 快速上手与操作指南

### 1. 启动工具
- 直接双击编译好的 `xhkk-builder.exe`（或从 GitHub Releases 下载解压直接运行）。
- 程序启动时会自动探测 `%APPDATA%\Rime`。若探测成功，底部状态栏会显示当前 Rime 配置路径和小狼毫部署器就绪状态。
- 如需更改配置路径，可点击底部状态栏右侧的 **「选择目录」** 按钮指定其他路径。

### 2. 选择目标词库
- **(●) 自用**：默认选中，添加至 `flypy.custom.dict.yaml`，适用于日常自定短语、网络热梗、专业缩写等（四码编码）；
- **( ) 人名**：添加至 `flypy.names.dict.yaml`，专用于亲友或公众人物姓名，三字人名将自动双写四码全码与三码简码。

### 3. 输入新词并微调读音
- 在“新词”输入框中敲入至少 2 个汉字（如 `深度学习`）；
- 编码框会自动生成四码（如 `ufxi`），下方单字读音栏展示各个单字的拼音与双拼映射 `[深: uf] [度: du] [学: xt] [习: xi]`；
- **调整多音字**：如果某个字有多音选项（如 `长`、`重`、`行`），对应的读音胶囊后会带有 `▾` 标记，**用鼠标左键单击胶囊**即可在候选读音中循环切换，编码框会实时同步刷新。

### 4. 一键提交并重新部署
- 检查右侧状态徽标：
  - 显示绿色 `[未收录]` 或黄色 `[重码: 当前首选为'xxx']` 时，即可提交；
- **直接按下回车键 `Enter`**（或点击「添加词条并重新部署」按钮）；
- 工具将自动写入词库文件，并在后台唤起小狼毫进行静默部署，输入框即刻清空重置，继续录入下一词。
